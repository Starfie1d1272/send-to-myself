# 小范围试用脚本

建议招募 5–10 位已有 NAS、经常在手机和电脑间交接内容的人，试用 7–14 天。此处为计划，尚无试用人数、通过率或用户反馈。先登记实际构件版本、来源和设备，使用参与者同意的测试内容；只记录任务结果和同意提供的反馈，不上传正文或附件做遥测。

1. 从干净 NAS 项目按[部署指南](DEPLOY.md)安装，记录到双端首次收发的时间、是否需要解释及卡住步骤。
2. 手机发送文字、链接、PNG 和 PDF；电脑复制、打开、保存；电脑再发一条链接给手机。只使用实际可安装且已验证的入口。
3. 短时断开隔离 NAS，观察 Web 草稿或鸿蒙队列；恢复后用原请求重试，检查同一次投递只有一条。记录未知状态，不将入队当作送达。
4. 使用真实取得并记录来源的升级包升级，检查旧记录和附件；在隔离路径恢复升级前备份并检查。没有配套升级包时标记未执行。
5. 一周后询问仍在使用的场景、使用天数和退回原工具的原因。

## 一分钟演示分镜

- 0–10 秒：打开 NAS 上的“发给自己”，说明已有 NAS 用户的场景。
- 10–30 秒：手机通过实际验证的系统分享入口发文字或链接和一张图。
- 30–45 秒：电脑查看、复制、打开并保存。
- 45–60 秒：演示文件搜索，以及待发送状态如何恢复。

只展示实际验证的入口和状态；不暴露真实口令、令牌或私密记录。此脚本不代表已招募、演示或完成设备验收。
